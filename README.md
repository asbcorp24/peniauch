# VocalLab — автономный тренажёр вокала

Проект для ESP32-S3 и HW-261 (VS1053B), сборка через PlatformIO.

## Первая версия: аппаратная диагностика

- Wi-Fi точка доступа `VocalLab` (`vocal1234`)
- Веб-интерфейс `http://192.168.4.1`
- Проверка SCI_STATUS / DREQ кодека VS1053B
- Проверка microSD и вывод результатов диагностики

**Запись голоса с HW-261 и анализ интонации пока не реализованы.** В рабочей ветке добавлены загрузка эталонного WAV через браузер и график RMS. Их добавим после проверки SPI и звукового тракта на физической плате.

## Сборка

Откройте папку репозитория в VS Code + PlatformIO. Выберите `esp32-s3-devkitc-1` и выполните **Build**, затем **Upload**. Монитор порта: 115200 бод.

Командная строка: `pio run`, `pio run -t upload`, `pio device monitor -b 115200`.

## Предполагаемые GPIO ESP32-S3

| Сигнал | GPIO |
|---|---:|
| SPI SCK | 12 |
| SPI MISO | 13 |
| SPI MOSI | 11 |
| VS1053 X_CS | 10 |
| VS1053 X_DCS | 9 |
| VS1053 DREQ | 14 |
| VS1053 X_RESET | 8 |
| SD_CS | 4 |

**Внимание:** это назначение GPIO на ESP32-S3, а не подтверждённая распиновка самого Shield. На HW-261 сверить связи контактов по схеме/прозвонке. Arduino Shield может питаться от 5 В, но входы ESP32-S3 НЕ допускают 5 В. Перед соединением и подачей питания проверить реальные уровни логики и питание VS1053B/microSD. Не считать пины Arduino D2/D6/D7/D8/D9 универсальными для всех ревизий HW-261.

## Ограничения

- Выбран базовый `esp32-s3-devkitc-1` без предположений о конкретном объёме Flash/PSRAM. Параметры изменим после определения модуля.
- Для точного анализа вокала позже потребуется получать подходящий декодируемый аудиопоток, оценить задержки и качество встроенного микрофона.

## Эталон WAV (рабочая ветка)

На `http://192.168.4.1` можно загрузить WAV-файл через форму. Он сохраняется на SD как `/reference.wav`; предыдущий эталон заменяется. Рекомендуемый формат: mono PCM 16-bit 16 kHz, максимум 12 МБ. График RMS вычисляется браузером из выбранного файла, а не микроконтроллером. Сервер пока не валидирует заголовок WAV — это прототип для доверенной локальной сети. API: `POST /api/reference` (multipart field `file`), `GET /api/reference`.

Для проверки аудиовыхода положите `/test.mp3` в корень microSD и используйте кнопки на странице. Проигрывание MP3 пока не проверено на железе и не выполняет полный штатный VS1053 endFill/cancel при остановке; тестируйте на коротких файлах. Не используйте тест как подтверждение корректности звукового тракта до физической проверки.
